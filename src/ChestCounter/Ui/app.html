OBS / TikTok Live Studio

L'overlay compact du jeu, pour OBS et TikTok Live Studio. Le lien HTTPS fonctionne dans les deux ; TikTok refuse les anciens liens HTTP.

Le domaine HTTPS pointe vers 127.0.0.1 : le trafic reste sur ce PC. Garde ChestCounterFortnite ouvert et laisse Internet résoudre le domaine. L'overlay s'adapte automatiquement à la source : aucun redimensionnement à faire. OBS peut aussi utiliser l'ancien lien HTTP déjà configuré.

Comment ça marche

Le compteur lit les replays que Fortnite enregistre et compte tes coffres quelques secondes après la fin de chaque partie. Garde la fenêtre ouverte pendant que tu joues : elle peut rester dans la zone de notification.

Rien n'est compté ?

Dans Fortnite, active Paramètres → Jeu → Rediffusions → Enregistrer les rediffusions. Les coffres apparaissent ensuite tout seuls.

L'overlay

Affiche ou masque-le avec Ctrl+Maj+O et verrouille-le avec Ctrl+Maj+L. Déverrouillé, maintiens le clic gauche pour le déplacer. En jeu, choisis « Plein écran fenêtré ».

Tes données

Tout est enregistré sur ce PC, dans %APPDATA%\ChestCounterFortnite : historique, réglages et rapport. Une fois connecté, ton historique est aussi copié dans ton compte Supabase ; les replays restent locaux. Les mises à jour se téléchargent automatiquement depuis GitHub.
